Customer Churn Prediction

Business Problem

Customer attrition reduces revenue and increases acquisition costs. The objective was to predict high-risk customers to enable proactive retention strategies.

Methodology

  • Data cleaning using Pandas
  • Feature engineering
  • Random Forest & Logistic Regression models
  • Evaluation using accuracy, recall, precision

Results

Random Forest achieved 84% accuracy with improved recall for churned customers.

Code Snippet


model = RandomForestClassifier()
model.fit(X_train, y_train)
accuracy = model.score(X_test, y_test)
